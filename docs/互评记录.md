# 互评记录

> T3 任务要求：组员 A 的 diff 给 B 起会话评审，处理意见后留"评审→整改"记录。
> 用法：复制下方模板作为一次互评记录，填完提交到本仓库（同一个文件追加多次记录即可，不必新建文件）。

---

## 模板（复制本节开始填写）

### 互评 #N：[简述评审对象，如「T1 测试补齐 diff」]

- 评审日期：YYYY-MM-DD
- 被评审人（diff 提供方）：[姓名 / Gitee 用户名]
- 评审人（起会话方）：[姓名 / Gitee 用户名]
- diff 来源：[commit 范围 `abc123..def456` / PR !N / 分支 `feat/xxx`]
- 评审会话工具：[Trae / ChatGPT / Claude / GitHub Copilot Chat 等]

#### 评审意见

| # | 类型 | 位置 | 意见 | 严重度 | 处理 |
|---|---|---|---|---|---|
| 1 | 正确性 / 可读性 / 安全 / 性能 / 约定 | 文件:行号 或 代码片段 | 具体问题描述 | 阻塞 / 建议 | 待整改 / 已整改 / 不采纳 |

#### 整改记录

| 意见 # | 处理方式 | 修复 commit | 说明 |
|---|---|---|---|
| 1 | 整改 / 不采纳（附理由） | `abc1234` | 简述改了什么 / 为何不采纳 |

#### 关闭

- 整改后 diff 复跑：[构建号 / `npm test` 输出 / 评审人复看]
- 评审人确认：[已确认 / 待确认]
- 关闭时间：YYYY-MM-DD
