# 演示脚本：「约→撞→取消→再约」90 秒闭环

> 对应任务看板 T10。演示时长约 90 秒，含闭环走查 + 审题三问问答。
> 演示环境：本地 `npm start`（http://localhost:3000）或线上 https://caojunyue.pages.dev/

## 前置准备

1. 启动后端：`npm start`
2. 打开浏览器：http://localhost:3000
3. 确认页面加载：三张器材卡片（投影仪 / 单反相机 / 便携音响）+ 页脚访问计数
4. 确认 seed 数据：卡片下应有 seed 示例预约（如投影仪明天某时段已被预约）

## 演示流程（约 60 秒）

### 步骤 1：新建预约（约→成功）

1. 点击「投影仪」卡片的「预约」按钮
2. 弹窗中填写：预约人「张三」
3. 选择日期：明天（或未来任意一天）
4. 选择时段：「第1-2节 08:00-09:35」
5. 点击「提交预约」
6. **预期**：弹窗关闭，toast 提示「预约成功」，投影仪卡片下方出现刚建的预约

### 步骤 2：撞单（撞→409 拒绝）

1. 再次点击「投影仪」卡片的「预约」按钮
2. 填写：同一个预约人「张三」（或换人「李四」也可以）
3. 选择：**同一日期 + 同一时段**「第1-2节 08:00-09:35」
4. 点击「提交预约」
5. **预期**：弹窗不关，红色错误提示「该器材在此时段已被预约，请更换日期或时段」
6. **讲解点**：互斥在服务端数据库唯一索引兜底，前端不本地判重，等服务端 409 再显示

### 步骤 3：取消预约（取消→释放）

1. 在投影仪卡片下找到刚才的预约
2. 点击该预约右侧的「取消」按钮
3. 浏览器弹出确认框，点击「确定」
4. **预期**：预约从列表消失，toast 提示「已取消预约」
5. **讲解点**：DELETE 成功返回 204，时段被释放

### 步骤 4：重新预约（再约→成功）

1. 再次点击「投影仪」卡片的「预约」按钮
2. 填写：同一日期 + 同一时段「第1-2节 08:00-09:35」
3. 点击「提交预约」
4. **预期**：预约成功——刚取消的时段可重新预约，闭环走通

### 步骤 5：展示加分项（可选，约 15 秒）

1. 点击右上角「📊 统计」按钮 → 展示柱状图（各器材预约量）+ 饼图（各时段热度）
2. 点击右上角「🤖 AI 助手」→ 输入「明天上午投影仪有空吗？」→ 展示 AI 回答

## 审题三问问答（约 30 秒）

### Q1：互斥规则在哪一层兜底？

**答**：数据库唯一索引。`db/schema.sql` 在 `bookings` 表上建了 `UNIQUE(equip_id, date, slot)` 唯一索引，同器材+同日+同时段的 INSERT 会被 SQLite 直接拒绝。后端 `createBooking()` 捕获 `SQLITE_CONSTRAINT` 异常，抛 `BookingConflictError`，路由层返回 409。

**为什么不在前端判重**：v1 曾用 localStorage 判重，但多设备/多标签页无法同步。v2 改为服务端唯一索引兜底，前端只管发请求、等服务端 409 再显示错误。判重唯一事实源是数据库，不是前端。

### Q2：前后端怎么协作完成 409 冲突处理？

**答**：前端 `submitBooking()` 发 `POST /api/bookings`，如果服务端返回 409，`res.ok` 为 false，`data.error` 含中文提示。前端 catch 后调 `showError(data.error)` 把错误显示在弹窗内的红色提示区，弹窗不关，用户可以改时段或改日期重试。

**关键**：前端不做任何本地判重逻辑，完全信任服务端返回的状态码。

### Q3：取消后时段为什么能重新预约？

**答**：`DELETE /api/bookings/:id` 执行的是 `DELETE FROM bookings WHERE id = ?`，直接从数据库删除该行。唯一索引约束只对 INSERT 生效，删除后该 `equip_id+date+slot` 组合不再存在，下次 INSERT 同组合不会触发 `SQLITE_CONSTRAINT`，所以能重新预约。测试规则 5 验证了这个闭环：DELETE 204 → POST 201。

## API 对应关系

| 演示步骤 | HTTP 请求 | 响应 |
|---------|----------|------|
| 步骤1 新建预约 | `POST /api/bookings` | `201 {id, equipId, user, date, slot, createdAt}` |
| 步骤2 撞单 | `POST /api/bookings`（同键） | `409 {error: "该器材在此时段已被预约..."}` |
| 步骤3 取消 | `DELETE /api/bookings/:id` | `204`（空 body） |
| 步骤4 重新预约 | `POST /api/bookings`（同键） | `201`（时段已释放） |

| # | 测试规则 | 对应步骤 |
