# 电梯稿：教务器材预约（组内互讲版）

> 一页讲清这个想法。场合：组内互讲 / 课堂展示开场。

## 一句话定位

给教务 / 社团场景用的**器材预约小工具**：选器材、选日期时段、提交预约，**同一器材同一时段自动互斥**，撞单当场拦截。

## 痛点

借器材靠纸质登记本或微信群接龙：

- **撞单靠人肉发现**——两个人约了同一台投影仪同一时段，到用的时候才发现；
- **记录查不动**——纸单翻不到、群消息刷没，谁借过、借几次说不清；
- **时段没释放**——有人不借了不吭声，别人以为还占着。

## 方案

三张器材卡片 + 一个预约弹窗，三步完成：

1. 选器材（投影仪 / 单反相机 / 便携音响）；
2. 选日期（过去日期直接拦截）和时段；
3. 填姓名提交——撞单时服务端返回 409，页面提示换时段。

取消也是一步：列表点取消、二次确认、时段立即释放，别人可约。

## 亮点（为什么值得看）

- **互斥是真兜底**：不是前端判断就完事——数据库唯一索引 `equip_id + date + slot`，冲突由服务端返回 409，双开页面也撞不进去；
- **零依赖可跑**：后端 Node 原生 http + 内置 `node:sqlite`，不装一个 npm 包；
- **有数据洞察**：Chart.js 统计弹窗，各器材预约量柱状图、各时段热度饼图，数据来自服务端聚合；
- **真的上线了**：Cloudflare Pages + D1 全球可访问，页脚有真实访问计数。

## 演示（90 秒闭环）

线上地址：https://caojunyue.pages.dev/

**约 → 撞 → 取消 → 再约**：

1. 约「投影仪 明天 上午」→ 成功；
2. 再约一次同时段 → 409 撞单提示；
3. 取消刚才那条 → 时段释放；
4. 重新约同时段 → 成功。右上角「📊 统计」看图表变化。
