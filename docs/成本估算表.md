## 六、成本优化说明

1. **云服务零成本**：Cloudflare Pages + D1 的 Free 计划完全覆盖本项目规模（预约记录 < 1k 条、日访问 < 1k 次），无需付费升级；
2. **LLM 成本可控**：DeepSeek 价格低于 GPT-4o 约 80%，且本项目 AI 助手使用频率低（教师偶尔查询），月成本 < ¥5；
3. **无服务器架构**：Functions 按调用计费，无空闲期成本，适合低流量教务场景；
4. **数据持久化**：D1 数据不丢失，无需额外备份存储成本。
