# 数据字典

> 基于 `db/schema.sql` 生成，数据库引擎 SQLite（本地 `node:sqlite` / 线上 Cloudflare D1）。
> 生成日期：2026-10-10

## 表清单

| 表名 | 说明 | 行数（典型） |
|------|------|-------------|
| `bookings` | 预约记录 | 动态增长 |
| `visits` | 页面访问计数（单行计数器） | 固定 1 行 |

---

## 表 `bookings`

预约记录。互斥唯一键为 `equip_id + date + slot`，即同一器材同一日期同一时段只能有一条预约。

| 字段 | 类型 | 约束 | 说明 | 取值示例 |
|------|------|------|------|----------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键，自增 | `1`, `2`, `3` |
| `equip_id` | TEXT | NOT NULL | 器材标识 | `projector` / `camera` / `speaker` |
| `user` | TEXT | NOT NULL | 预约人姓名（最长 20 字） | `张三` |
| `date` | TEXT | NOT NULL | 预约日期，格式 YYYY-MM-DD | `2026-10-15` |
| `slot` | TEXT | NOT NULL | 时段（5 个固定值之一） | `第3-4节 10:00-11:35` |
| `created_at` | INTEGER | NOT NULL | 创建时间，毫秒时间戳 | `1728000000000` |

### 索引

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| `uk_equip_date_slot` | UNIQUE | `equip_id, date, slot` | 互斥唯一键，防止同一器材同一日期同一时段重复预约 |

### 时段取值（`slot`）

| 值 | 说明 |
|----|------|
| `第1-2节 08:00-09:35` | 上午 1-2 节 |
| `第3-4节 10:00-11:35` | 上午 3-4 节 |
| `第5-6节 14:00-15:35` | 下午 5-6 节 |
| `第7-8节 16:00-17:35` | 下午 7-8 节 |
| `晚间 19:00-21:00` | 晚间 |

### 器材取值（`equip_id`）

| 值 | 名称 | 型号 |
|----|------|------|
| `projector` | 投影仪 | Epson CB-FH06 |
| `camera` | 单反相机 | Canon EOS 200D II |
| `speaker` | 便携音响 | JBL Charge 5 |

---

## 表 `visits`

页面访问计数。单行计数器，`id` 固定为 1，每次访问首页 `count` 自增 1。

| 字段 | 类型 | 约束 | 说明 | 取值示例 |
|------|------|------|------|----------|
| `id` | INTEGER | PRIMARY KEY CHECK (id = 1) | 主键，固定为 1 | `1` |
| `count` | INTEGER | NOT NULL DEFAULT 0 | 访问次数 | `42` |

### 索引

无（单行表，无需索引）。

---

## 数据初始化

`db/seed.sql` 在首次建库时插入 2 条预约示例数据：

| equip_id | user | date | slot |
|----------|------|------|------|
| `projector` | 示例-张三 | 明天日期 | `第3-4节 10:00-11:35` |
| `camera` | 示例-李四 | 明天日期 | `第5-6节 14:00-15:35` |

`visits` 表初始化 `id=1, count=0`（由 `schema.sql` 的 `INSERT OR IGNORE` 完成）。

---

## 互斥规则说明

业务规则：同一器材 + 同一日期 + 同一时段不可重复预约。

- **数据库层兜底**：唯一索引 `uk_equip_date_slot`，并发穿透时由 SQLite 抛出 `UNIQUE constraint failed`，服务端转 409。
- **服务层主防线**：`BookingService.createBooking()` 先 `existsByVenueIdAndBookingDateAndTimeSlot` 查重，命中即抛 `BookingConflictException` → 409。

（注：以上服务层描述对应组员仓库 vibe-weilan；本仓库 backend/db.js 由唯一索引 + `INSERT OR IGNORE` 实现，判重逻辑在 `createBooking` 内。）
