01部署平台演进

问题

Sealos / Render 免费层不可用

Sealos cloud.sealos.io 改版后创建项目流程与教程差距大、登录卡死；Render 免费层 15 分钟无请求休眠，重启清库——预约数据回 seed、访问计数归零。

解决

改用 Cloudflare Pages + Functions + D1

pages.dev 国内可直连、Free $0/月、无信用卡、边缘运行无休眠、D1 数据库持久化不丢。新增 functions/ 子树（ESM）+ wrangler.toml D1 binding。

结果：5 个验收 URL 全通过，教师手机可开，数据不丢。

02互斥判重从前端迁到服务端

问题

localStorage 前端判重跨设备失效

v1 用浏览器 localStorage 存预约 + 前端判重：A 设备约了，B 设备看不到，会撞单；浏览器清缓存后判重数据全丢。

解决

服务端数据库唯一索引 + 409

schema.sql 建 UNIQUE(equip_id, date, slot) 唯一索引；POST /api/bookings 插入冲突返回 409；前端不再本地判重，以服务端 409 为唯一事实源。

结果：跨设备撞单由数据库兜底，前端 v1 localStorage 判重逻辑已废弃。

03CI 踩坑（Gitee Go）

问题

YAML schema 与直觉不同 + 通知不可达

  • commands 多行块报"steps 配置缺失"
  • 按分支发现 YAML，主线 main 但默认分支 master
  • 社区版站内信/邮件均收不到（成功失败皆然）
  • build@nodejs 插件最高 15.x，跑不了 node:sqlite
解决

按 schema 重写 + 双分支同步

  • commands 改字符串列表（链式单行）
  • git push origin main:master 同步
  • 以构建历史页状态为准（README 踩坑 4 记录）
  • npmmirror 源自装 Node 22 后 npm test
结果：push → 装依赖 → 跑测试全绿；故意失败验证 CI 拦截有效。

04跨环境一致性

问题

Functions 命名限制 + 402 状态码不一致

  • Cloudflare Pages Functions 的 DELETE 处理器用 onDelete 命名 → 405
  • DeepSeek 402（余额不足）：本地后端映射 QUOTA→429；线上 Functions 直接返回 503
解决

对齐命名 + 统一状态码映射

  • DELETE 处理器改名 onRequestDelete（commit 204e76f）
  • 线上 Functions 的 402 分支改返回 429（commit b3a1fa3）
  • 与本地 backend/ai.js 的 QUOTA→429 映射对齐
结果：本地与线上同代码同行为，AI 助手失败兜底一致。

05测试可重入性 + 总结

问题

测试跑挂三连击

  • Node 22 Windows 下 --test tests/ 报 Cannot find module
  • 断言消息里 await res.text() 提前消费响应流
  • 用例未清理残留数据，共用互斥键连锁 409
解决

改用例不改业务

  • 改 --test tests/api.test.js（具体文件路径）
  • 先读 body 再断言（createOk 辅助函数）
  • before 钩子清库 + 用例 try/finally 自清
5 条业务规则全绿且连跑可重入；业务代码零改动。
所有问题已闭环，现场能跑：https://caojunyue.pages.dev/
